Private activity, visitor map, and export

The activity report covers the last 30 days, up to 10,000 records. New interaction details are available only after the enhanced tracking was added. Search Console is not connected: search keywords are not part of this report. About Google's aggregate search-performance report.

The private IP map uses retained IP addresses from the same loaded 30-day report, up to 10,000 records. Select a location, then an IP address, to inspect its recorded activity. Counts describe distinct IP addresses and events, not people. First and last seen refer only to the loaded records. Network-derived locations are approximate, not GPS positions; some records have no usable coordinates.

Drag the map to move, or use the mouse wheel, pinch gesture, or controls to zoom. The tile provider receives ordinary map-tile requests, never IP records or your token. The CSV export retrieves all available records in batches of 5,000 and includes raw IP addresses only for records no more than 30 days old, plus approximate country, region, city, postal code, coordinates, and network organization.

The token is used only for the requested action and is never saved. Private results are cleared on a new request or when leaving this page. Delete downloaded CSV files within 30 days; local copies are outside the website's automatic cleanup.
