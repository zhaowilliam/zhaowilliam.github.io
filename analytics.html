Private activity, visitor map, and export

The activity report covers the last 30 days, up to 10,000 records. New interaction details are available only after the enhanced tracking was added. Search Console is not connected: search keywords are not part of this report. About Google's aggregate search-performance report.

View approximate city-level visitor locations on an interactive satellite map or download all page-view and click records as one CSV. Each marker represents one city-level location; marker size reflects the approximate visitor count. Drag to move the map, or use the mouse wheel, pinch gesture, or controls to zoom. The map receives only aggregated locations and counts—never IP addresses or visitor identifiers. The export retrieves records in batches of 5,000 and includes raw IP addresses only for records no more than 30 days old, plus approximate country, region, city, postal code, coordinates, and network organization. Location is inferred from the network connection and is not GPS-level positioning.

The token is used only for the requested action and is never saved. Private results are cleared on a new request or when leaving this page. Delete downloaded CSV files within 30 days; local copies are outside the website's automatic cleanup.
