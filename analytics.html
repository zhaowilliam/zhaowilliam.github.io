Private event export

Download all available page-view and click records as one CSV. The export retrieves records in batches of 5,000. It includes raw IP addresses only for records no more than 30 days old, plus approximate country, region, city, postal code, coordinates, and network organization. Location is inferred from the network connection and is not GPS-level positioning.

The token is used only for this request and is not stored in the page. Delete downloaded CSV files within 30 days; local copies are outside the website's automatic cleanup.
